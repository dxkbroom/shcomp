# shcomp 0.0.3

A quality-of-life release for zsh and fish. No new shells and no new registry
items: shcomp explains itself, cleans up after itself, arrives warm, and can
complete a command no registry knows. `CHANGELOG.md` has the full list.

Released 2026-11-19.

## Highlights

- `shcomp which <command>` explains one command end to end — selection,
  registry layer, binary, and per shell the source, cache key and state, shim,
  and last load — without ever running it.
- `shcomp add leaf --run 'leaf --auto-complete {shell}:dump'` describes a
  command the registry does not know. `--run-zsh`, `--run-fish`,
  `--url --shell`, and `--usage` work too. `add` checks the command is on
  `PATH`, runs the source once per shell, and shows the `[[registry]]` item
  before writing it. `add` also accepts several references.
- `shcomp edit` edits the config in `$EDITOR` and writes it only when it
  parses, validates, and resolves. Then it shows the diff and reconciles.
- `install` prewarms by default, so the first Tab is warm. `add` prewarms what
  it added, and `--no-prewarm` or `[settings].prewarm = false` opts out.
- `doctor` checks fish the way it checks zsh. It warns when two config keys
  select the same tool (`tv` and `alexpasmantier/television/tv`) and reports
  generators that failed silently at a Tab. `doctor --check` asks your real
  interactive zsh and fish whether the loading line is in effect, whether
  something shadows a shim, and whether a static `_shcomp` from v0.0.1 is still
  around.
- Cached scripts record where they came from. `shcomp clean --stale` (with
  `-n`) removes the ones no Tab can reach, `clean <tool>` and `clean -s <shell>`
  scope a removal, and `install` prunes quietly.
- `ls` shows every shell's cache state (`warm/cold`), and `ls --shell fish`
  narrows to one. `complete-word` defaults to your `$SHELL` when that is zsh or
  fish.

## Behavior changes

- `install` now generates scripts, which runs each selected tool's generator
  once. Use `--no-prewarm` to keep the old behavior.
- `ls`'s `Cache` column holds one state per shell. `ls --json` keeps `cache`
  and adds `caches`.
- `complete-word --shell` defaults to `$SHELL` when that is zsh or fish.
- `install` and `add` stop printing the loading line for a shell once shcomp
  has seen it in effect.
- shcomp's own mise packslip overlap is an `ok` line in `doctor`.

Run `shcomp install` after upgrading. Scripts cached by 0.0.2 are pruned and
regenerated for 0.0.3.
